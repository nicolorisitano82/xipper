Xipper XIZ per Windows
======================

Apre, verifica ed estrae gli archivi XIZ creati con Xipper (macOS). Non crea archivi (per ora).

Uso
---
- Doppio clic su XipperXIZ.exe, poi Apri… o trascina un file .xiz nella finestra.
- File > "Apri i file .xiz con Xipper XIZ": i file .xiz si aprono con un doppio clic, e il menu
  di Esplora file offre "Estrai qui" ed "Estrai in…" (su Windows 11 sotto "Mostra altre opzioni").
  Non servono diritti di amministratore; File > "Rimuovi l'associazione" la toglie.
- Archivi protetti: password e, se richiesto, il file del secondo fattore (.xizfactor). Per gli
  archivi con destinatari o custodi la finestra elenca come si aprono: si aggiungono password e file
  di chiave (XIZ-SECRET-KEY-…, AGE-SECRET-KEY-…). Con un gruppo bloccato, File > "Sblocca altri gruppi".
- File > Firme: chi ha firmato ogni segmento e se la firma è valida. File > Proprietà (Alt+Invio).
- Verifica controlla anche il recovery record; se l'archivio è danneggiato e riparabile, "Ripara
  una copia" crea "nome (riparato).xiz" senza toccare l'originale.
- File > "Verifica una prova di inclusione": un file e la sua prova .json, senza l'archivio.
- Doppio clic su un file dell'elenco: lo apre col suo programma. Trascinando la selezione su
  Esplora file la si estrae lì. In entrambi i casi i file passano da una cartella temporanea
  privata, cancellata alla chiusura.
- Lingue: italiano, inglese, tedesco, spagnolo, francese, giapponese e cinese semplificato,
  secondo la lingua di Windows.
- I file estratti da un archivio scaricato da Internet ricevono lo stesso contrassegno
  (Mark of the Web): Windows continua ad avvisare prima di aprire un programma.

Riga di comando
---------------
  XipperXIZ archivio.xiz                 apre la finestra
  XipperXIZ /x archivio.xiz [/d CARTELLA] estrae (default: una cartella col nome dell'archivio)
  XipperXIZ /xto archivio.xiz            chiede dove estrarre
  XipperXIZ /t archivio.xiz              verifica (anche il recovery record)
  XipperXIZ /repair archivio.xiz         ripara una copia
  XipperXIZ /info archivio.xiz           proprietà e firme
  credenziali: /passenv VARIABILE, /identity FILE, /factor FILE (ripetibili)
  XipperXIZ /register | /unregister      associa i file .xiz, o no
Per gli script c'è anche xiz.exe (xiz --help).

Avviso al primo avvio
---------------------
L'eseguibile non ha una firma commerciale: Windows può mostrare "Windows ha protetto il PC".
Controlla lo SHA-256 del file scaricato (pubblicato accanto allo zip), poi "Ulteriori
informazioni" > "Esegui comunque".

Limiti
------
- Gli archivi compressi con LZRAVEN o LZMESH (codec Apple, solo macOS 27) non si aprono.
- Le marche temporali RFC 3161 sono mostrate, non verificate; la catena dei certificati non è
  validata (l'impronta SHA-256 permette di confrontarla).
