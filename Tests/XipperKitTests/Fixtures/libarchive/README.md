ZIP and 7z test vectors from libarchive 3.8.11 (`libarchive/test/test_read_format_zip*.uu`,
`test_read_format_7zip*.uu`, uudecoded), BSD-2-Clause like libarchive (see Vendor/libarchive/COPYING).
Written by many tools (WinZip, PKWARE, 7-Zip, Info-ZIP, jar, Windows code pages, SFX modules) plus
malformed and fuzzing cases. `LibarchiveVectorTests` says which must read and which must be refused.
